## 1. Сборка и прошивка через VS Code (PlatformIO)

Проект EHU32 полностью переведён на современную среду разработки **PlatformIO** под ядро **Arduino Core 3.1.0 / ESP-IDF 5.3.0**. Все параметры компилятора, флаги IRAM и зависимости библиотек зафиксированы в файле конфигурации `platformio.ini`.

```text
[ Исходный код EHU32 ] ──► [ PlatformIO / SCons ] ──► [ Автозагрузка библиотек ] ──► [ Сборка .bin ]
                                                                                            │
                                   Прошивка через esptool (921600 бод) ◄────────────────────┘
```

### Пошаговая инструкция по сборке (4 шага):

1. **Установка среды:**
   * Установите редактор **[VS Code](https://code.visualstudio.com/)**.
   * В разделе расширений (Extensions, `Ctrl+Shift+X`) найдите и установите **PlatformIO IDE**.
2. **Открытие проекта:**
   * Нажмите **Файл → Открыть папку...** (File → Open Folder) и выберите корневую папку с проектом.
   * Дождитесь окончания первичной индексации (PlatformIO автоматически подтянет правильный тулчейн `pioarduino 53.03.10` и библиотеку `ESP32-A2DP v1.8.11`).
3. **Выбор COM-порта:**
   * Откройте файл `platformio.ini` в корне проекта.
   * Укажите номер COM-порта вашей платы в блоке окружения (например, `upload_port = COM3` и `monitor_port = COM3`).
4. **Сборка и прошивка:**
   * Нажмите кнопку **Upload** (синяя стрелочка `➔` на нижней статусной строке VS Code) либо выполните в терминале:
     ```bash
     pio run -t upload
     ```

> ⚠️ **Вход в режим прошивки (BOOT):** На некоторых платах ESP32 DevKit при начале прошивки (когда в терминале побегут точки `Connecting........`) необходимо **зажать кнопку BOOT на плате на 1–2 секунды**, пока не начнётся процентная запись секторов памяти.

## 2. Таблица разделов Flash-памяти (Dual-OTA Setup)

Проект использует специализированную таблицу разделов **`min_spiffs.csv`** для поддержки беспроводного обновления по воздуху (Dual OTA):

| Раздел | Тип | Смещение (Offset) | Размер | Назначение |
|:---|:---:|:---:|:---:|:---|
| **`nvs`** | data (nvs) | `0x09000` | 20 КБ | Хранение настроек EHU32 (ID дисплея, флаги комплектации авто) |
| **`otadata`** | data (ota) | `0x0E000` | 8 КБ | Системный указатель активного слота загрузки прошивки |
| **`app0`** | app (ota_0)| `0x10000` | **1.875 МБ** | Основной рабочий слот прошивки микроконтроллера |
| **`app1`** | app (ota_1)| `0x1F0000`| **1.875 МБ** | Резервный слот для беспроводного обновления по воздуху |
| **`spiffs`** | data | `0x3D0000` | 128 КБ | Файловая система SPIFFS |
| **`coredump`**| data | `0x3F0000` | 64 КБ | Системный раздел дампов памяти при критических сбоях |

## 3. Полная очистка памяти (Erase Flash) перед первой прошивкой

Если на плате ранее были записаны сторонние прошивки или повреждены ключи NVS, рекомендуется выполнить полное стирание памяти перед установкой:

* **Через терминал PlatformIO:**
  ```bash
  pio run -t erase
  ```
* **Через графический интерфейс:** В меню PlatformIO (иконка 👽 слева) выберите **`Project Tasks` ➔ `esp32_ehu32_v2` ➔ `Platform` ➔ `Erase Flash`**.
* После стирания запустите стандартную прошивку `pio run -t upload`.

## 4. Беспроводное обновление прошивки по Wi-Fi (ArduinoOTA)

Шлюз EHU32 поддерживает обновление прошивки по воздуху без необходимости извлекать магнитолу из приборной панели.

```text
[ Кнопка 8 (зажата >= 1 с) ] ──► [ Старт SoftAP EHU32-XXXX ] ──► [ Подключение ПК к Wi-Fi ] ──► [ OTA Flash ]
```

### Порядок беспроводной прошивки:

1. **Запуск режима OTA:**
   * Включите магнитолу.
   * **Зажмите и удерживайте кнопку «8» на панели магнитолы не менее 1 секунды.**
   * EHU32 остановит Bluetooth A2DP, снимет блокировку экрана и запустит точку доступа Wi-Fi.
   * На экране автомобиля (GID/CID) отобразится сервисный баннер:
     * **SSID сети:** `EHU32-XXXX` (где XXXX — последние 4 символа MAC-адреса платы).
     * **Пароль:** `ehu32updater`.
2. **Подключение компьютера к точке доступа:**
   * В списке сетей Wi-Fi вашего ноутбука найдите сеть `EHU32-XXXX` и подключитесь к ней с паролем `ehu32updater`.
3. **Загрузка прошивки из PlatformIO:**
   * В файле `platformio.ini` временно укажите IP-адрес шлюза:
     ```ini
     upload_port = 192.168.4.1
     upload_flags = --auth=ehu32updater
     ```
   * Нажмите **Upload** — прошивка загрузится по воздуху за 15–20 секунд. На экране авто будет отображаться прогресс: `Updating... 10% ... 100%`.
   * После завершения ESP32 автоматически перезагрузится в новую прошивку.

> ℹ️ **Аварийный выход из OTA:** Если вы случайно активировали режим OTA, удерживайте кнопку **«8» на магнитоле более 5 секунд** — плата прервёт ожидание и перезагрузится в штатный режим. Также действует автоматический таймаут 10 минут при отсутствии активности.

## 5. Прошивка со смартфона через USB-OTG (ESPflash)

Если у вас нет ноутбука под рукой, прошить плату ESP32 можно прямо со смартфона на Android:

1. Установите приложение **ESPflash** (или **Serial USB Terminal**) из Google Play.
2. Подключите плату ESP32 к разъёму Type-C смартфона через стандартный **USB-OTG адаптер**.
3. Скомпилированный файл прошивки `firmware.bin` (находится в папке проекта `.pio/build/esp32_ehu32_v2/firmware.bin`) сохраните в память телефона.
4. В приложении ESPflash:
   * Выберите чип: **ESP32**.
   * Выберите файл `firmware.bin`.
   * **КРИТИЧЕСКИ ВАЖНО:** Укажите стартовый адрес записи (Flash Offset): **`0x10000`**.
   * Нажмите кнопку **Flash / Write** и дождитесь окончания прошивки.
